## Description of Website:
Our website allows aspiring chefs of all skill levels to share their creative recipes with each other, including images, instructions, ingredients, and descriptions. Users can browse recipes and save their favorite ones and well as author their own recipes. In addition, users will be able to comment and leave reviews on each other's recipes and play a fun, food-related game.

### Install Guide:
1. **Clone the repository**: `git clone git@github.com:ashli64/tacos.git`
2. **Navigate into directory**: `cd tacos`
3. **Create virtual environment**: `python3 -m venv venv`
4. **Activate virtual environment**:
  - maxOs/Linux: `. venv/bin/activate`
  - Windows: `venv\Scripts\activate`
5. **Install dependencies**: `pip install -r requirements.txt`

### Launch Codes:
In the terminal, access the project root directory `cd app` and run the following commands:
- `~$ python3 __init__.py`

### Launch Website
Using the provided, locally hosted link, access the website.
